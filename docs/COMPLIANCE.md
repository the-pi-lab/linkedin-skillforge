# Compliance Guide

Legitimate use only. Forbidden: credential theft, hijacking, auth/CAPTCHA bypass,
enforcement evasion, rate-limit abuse, unauthorized access, impersonation, spam-at-scale.

Automation requirements: official/approved path, human approval for sends/posts/writes,
disclosed caps, opt-out, audit log. Use `automation-compliance` skill to score risk
(block / needs-review / approved with guards).
