# LinkedIn Algorithm Optimization (`linkedin.algorithm-optimization`)

Earn distribution honestly: diagnose why posts under-distribute (hook, dwell, early engagement, format fit), then tune controllable levers — structure, timing, comments stewardship — without gaming, pods, or bait.

## Install

Copy `skills/algorithm-optimization/` into your agent skills folder. No dependencies.

## Quickstart

1. Read `SKILL.md` (reasoning) + `schema.json` (validation).
2. Supply inputs: `posts`.
3. Wire tools if available (get_analytics); otherwise analysis-only mode.
4. Validate output envelope (`data` + `provenance` with confidence/gaps).

## Compose

Consumes Posts + metrics; produces Tuning plan → content-creation, content-scheduling. See `SKILL.md → Chaining`.
