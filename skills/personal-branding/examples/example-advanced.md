# LinkedIn Personal Branding — Advanced / composition example

## Scenario

Regulated employee (finance) with restricted topics; brand excludes advice, leans on process + career narrative.

## Input

```json
{"background": "analyst, bank", "constraints": "no investment advice", "goals": "career credibility"}
```

## Output (abridged)

```json
{"data": {"pillars": ["career notes","process","book notes"], "exclusions": ["investment advice"]}, "provenance": {"confidence": 0.7, "gaps": ["external proof"]}}
```

Notes: demonstrates Brand book → content-creation, engagement-strategy, employer-branding consumed downstream, degraded confidence on gaps, no fabricated facts.
