# LinkedIn Content Creation — Advanced / composition example

Founder with one story, needs week of content: one story repurposed across 4 formats without repetition.

## Input

```json
{"pillars": ["founder lessons"], "proof": "one churn story", "volume": "4"}
```

## Output (abridged)

```json
{"data": {"briefs": ["text story", "carousel framework", "poll debate", "article deep-dive"]}, "provenance": {"confidence": 0.72, "gaps": ["metrics unconfirmed"]}}
```

Notes: demonstrates ContentIdea[] + briefs → ai-content-generation, copywriting, content-scheduling consumed downstream, degraded confidence on gaps, no fabricated facts.
