Overbroad ICP ('all CEOs'); skill narrows to testable ICP + 20-lead sample with precision estimate.

## Input

```json
{"offer": "generic agency", "icp_hints": "CEOs everywhere"}
```

## Output (abridged)

```json
{"data": {"icp": {"titles": ["CEO 11-50 SaaS US"], "exclusions": ["enterprise", "services"]}}, "provenance": {"confidence": 0.6, "gaps": ["trigger signals"]}}
```

Notes: demonstrates ICP + Lead[] → prospect-research, lead-qualification, sales-navigator consumed downstream, degraded confidence on gaps, no fabricated facts.
