# LinkedIn Employer Branding (`linkedin.employer-branding`)

Make great candidates choose you: codify EVP (what's true + differentiating), gather proof (stories, data, voices), set content pillars + cadence, and define talent metrics — so hiring content compounds instead of random perks posts.

## Install

Copy `skills/employer-branding/` into your agent skills folder. No dependencies.

## Quickstart

1. Read `SKILL.md` (reasoning) + `schema.json` (validation).
2. Supply inputs: `company`, `talent`.
3. Wire tools if available (get_company); otherwise analysis-only mode.
4. Validate output envelope (`data` + `provenance` with confidence/gaps).

## Compose

Consumes Company + talent definition; produces EVP + pillars → content-creation, recruitment-automation. See `SKILL.md → Chaining`.
